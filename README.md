The best offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words that cites its sources, a checklist with progress saved in the browser, filters by grade and kind, a spoiler setting that hides story trophies until earned, a four-stage roadmap to the platinum, and a missable watch. Works fully offline — no network requests, no accounts, no tracking.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
